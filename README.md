## 📌 Project Overview

**Traveloop – Personalized Travel Planning Made Easy**

Traveloop is a personalized and intelligent travel planning platform that helps users create, organize, and share multi-city trips with ease.

The application allows users to:

- Create customized multi-city itineraries
- Add travel stops, dates, and activities
- Search and discover cities and attractions
- Automatically estimate trip budgets
- View day-wise travel timelines
- Maintain packing checklists
- Save trip notes and reminders
- Share itineraries publicly with friend

The goal of Traveloop is to simplify complex travel planning by combining itinerary management, budget tracking, and collaboration into one responsive web application.

This project was developed for the **Odoo × Parul University Hackathon 2026** using:

- **Spring Boot** for backend
- **React.js** for frontend
- **MySQL** for relational database(MySQL)
- **Python AI/ML** for Weather recommendation

## 🔐 Authentication – Login / Signup

## ✈️ Dynamic Destination Preview

## 🏁 Conclusion

Traveloop is a comprehensive and user-friendly travel planning platform that simplifies the process of organizing personalized multi-city trips.

With features such as secure authentication, dynamic destination previews, trip creation, itinerary building, budget tracking, and trip management, the application provides travelers with everything they need to plan and manage their journeys efficiently.

Built using **Spring Boot**, **React**, **MySQL**, and optional **AI/ML integration**, Traveloop demonstrates a scalable full-stack architecture and delivers a modern, responsive user experience.

This project successfully fulfills the hackathon objective of creating an intelligent and collaborative platform that makes travel planning simple, interactive, and enjoyable.
